# EL-NF3 prospective preregistration v1.1 — scoring protocol refinements

**2026-10-30 JST. This is a PRE-MEASURED-SCORING amendment. No KEMAR real SOFA has been downloaded, inspected by the research code or scored, no NF3 holdout results exist.** v1 at immutable commit `df6addb58296e9945569ff3473aa65039ef959cb` records scientific intent, and is superseded *for future execution only* by this version. Keep the original unchanged; do not recategorize prior experiments.

The v1 thresholds, S1/S2 definitions, model set, buffer, 80% geometric coverage requirement and strict claim limits remain. To prevent practical implementation discretion affecting G3, freeze the following protocol before original data is accessed:

1. **Deterministic target density.** For each heldout 20°×10° angular block and target distance {0.20,0.30,0.40,0.50}m, select EXACTLY ONE observed measurement: first minimize absolute radial distance to desired radius (must be <=0.004m), then angular distance to the block center, finally original measurement index. Selection uses source coordinates only. The evaluation observation unit is an angular block; one selected position/radius avoids treating 1cm neighbors as independent. Log both all eligible blocks and any unsampled/unsupported blocks.
2. **Roles.** Geometry-only hash ranks angle-block keys; floor(0.20*N) each final, calibration, selection, remaining train. Maintain >=5° spatial buffer around final blocks for *all non-final* acoustic groups. For S2 train all response samples ONLY at radius .20 or .50m (<=.004m tolerance); no data from .30/.40m anywhere in predictor construction, selected-baseline choice or risk calibration. Evaluation is .30/.40m.
3. **Baseline choice.** Pick one of B0/B1/B2/C1 using pooled median four-band ILD across S1 and S2 model-selection blocks that the candidate can support; tie-break by simpler listed method. If a baseline cannot support >=8 independent selection blocks per fold, exclude it from selection. Compare chosen baseline and C2 on exactly the *same* accepted final locations; never change baseline on final data. Also report B0 separately even if not selected.
4. **C2 refusal calibration.** First geometric hull and angular simplex max edge <=25° and radial gap <=.301m. On calibration angular blocks, freeze an additional monotone geometry difficulty threshold `angular_span_deg + 5 * radial_gap_m` at 80th percentile of the eligible calibration-score distribution. This is a **geometry-only operational selection rule**, not a statistically proven risk bound. Quantify measured residual calibration against final later. Record both geometric-only and calibrated-guard final coverage, and conditional errors; report 60/80/100% matched-coverage curves where actually supported. Refusals count against coverage, not as perfect predictions.
5. **Non-inferiority guards.** Compared on the same accepted target positions: pooled median ITD absolute error <= baseline+25 microseconds; two-ear centered log-spectral-shape RMSE median <= baseline+0.5 dB, and 95th-percentile four-band ILD error <= baseline+1.0dB. All are engineering tolerances, not perceptual thresholds. No absolute Pa metric.
6. **Bootstrap.** Resample distinct final angular blocks with replacement using NumPy PCG64 generator seed 20261030, 2000 draws. Within each draw retain S1/S2 radius and frequency-band records as correlated. Paired `median(baseline errors)-median(C2 errors)`; 2.5/97.5 percentiles. Report number of independent accepted blocks (minimum 8 in each S1/S2). CI excludes zero only if lower bound >0.
7. **Program integrity.** Fail-closed on original MD5, SOFA metadata units, nonzero Data.Delay without handling, licensing uncertainty for distribution, degenerate triangulation, missing radial shell, unexpected source orientation, or inability to establish valid measured relative L/R channel relationship. Numeric empirical verdict is INDETERMINATE if key physical metadata unknown for the claimed target. May report *exploratory relative-shape* metrics with explicit status but not promote as validated physical receiver.
8. **No secret data-driven rescue.** If original topology cannot satisfy these comparisons, report INDETERMINATE and propose a *separately frozen successor*; never adjust this protocol after opening final IR. Synthetic unit tests before original data are implementation checks, not evidence.

Original claims and v1 records remain available for independent audit. This extension does not authorize Core, Studio or ASMR runtime modifications.

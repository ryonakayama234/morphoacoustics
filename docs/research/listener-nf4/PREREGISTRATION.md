# EL-NF4 — PREREGISTRATION v1 (D0, prior to code or new measured HRIR scoring)

**Date:** 2026-10-31 JST. **Status:** FROZEN INTENT / RESEARCH_ONLY. The immutable Git commit containing this document is the D0 origin. No SCUT real-data acoustics have yet been downloaded or scored by EL-NF4 at D0.

## Research claim and hypotheses
H1: On spatially blocked, new directional regions of one measured head, arrival-separated regularized SH×radial-basis C3 improves four-band measured ILD against strongest eligible simple baseline (B0 nearest, B1 IDW, B2 barycentric, B3 SH).
H2: C4 bounded local residual correction adds accuracy without uncalibrated high-error tails.
H3: A separate empirically calibrated acceptance rule can retain >=80% eligible queried locations while blocking predictably poor cases. Coverage must be computed on ALL eligible final queries, not merely accepted predictions.
H4: A frozen learning *method* generalizes to separately measured heads after each head is partially measured; not a zero-shot predictor for unmeasured listeners.

## Physical measurand and boundary
Predict left/right measured HRIR conditioned on measured source coordinates in listener coordinate frame, fixed source+head, sample rate and data-specific measurement plane. Derive four ILD bands 500-1000,1000-2000,2000-4000,4000-8000 Hz, ITD as explicitly declared cross-correlation proxy, and centered monaural spectral-shape error. No absolute Pascal, physical tympanic prediction, ear-canal double filtering, source load, 1 cm contact, unmeasured elevation/radial extrapolation, time-varying head or ASMR perception. Unverified microphone plane limits labels to RELATIVE_MEASURED_HRIR_EXPLORATORY.

## Geometry-only allocation protocol
Select individual fixed subject SOFA files in ascending subject-id. Development: IDs 0001-0006. Acceptance calibration: 0007-0008. Locked final confirmation: 0009-0010, if all qualify. In all roles, a given held-out angular block is never used in acoustic model fitting on the same head; angle groups are consistent across heads so a final angular block is never used acoustically in development. Angle partition should maximize physical angular holdout separation, with recorded buffer. Assign direction groups deterministically by coarse az/el angular blocks and SHA256 seed 'EL-NF4-20261031'; exact geometry-only algorithm, radial target pairs and count are to be fixed in G0 v1.1 before the original HRIR values are accessed. This limited amendment is allowed only for source-coordinate topology/metadata and cannot inspect acoustic responses.
S1: withheld angular block with in-range measured radial shells available in training. S2: withheld angular block AND a target interior radial shell removed from all model fitting for the subject. Radius target must have a measured shorter and longer radial shell. Explicitly disallow training on final directions even if the subject is in a different role. Query positions may be geometrically known to all models but target IR is strictly masked until prediction artifact sealed.
Unit of dependence is angular block, not dense location count; no resampling 48kHz FIR taps or multiple radii as independent participants.

## Candidate algorithms / baselines
B0 closest Cartesian measured HRIR; B1 4-neighbor raw inverse distance FIR; B2 tetrahedral barycentric only if valid inside convex hull (report refusals); B3 ridge SH on complex measured HRTFs with radial basis; C3 per-ear arrival-separated HRIR then ridge SH×radial basis with train-only arrival model; C4 C3 plus support-bounded kernel residual. Models use train data only. Any library method such as SUpDEq is only a claim comparator if independently reproducible with the appropriate license and measured topology. C4 cannot silently fall back to C3 while claiming C4 if a correction fails.
Hyperparameters chosen on development-only split; acceptance calibrated on separate held-out calibration roles; no final model choice, threshold adjustment or data peeking.

## Final gates / decisions (proposed frozen numerical thresholds)
G3 PASS_LIMITED_NUMERIC only if C3 or C4 supported at >=80% of all eligible final query positions; median pooled 4-band absolute ILD <= 0.85 × strongest eligible baseline on EXACT same accepted positions; paired angular-block 95% bootstrap CI lower bound for baseline-minus-candidate median difference >0; positive improvement in both S1 and S2; ITD median ≤ baseline+25 μs; centered monaural spectral-shape RMSE median ≤baseline+0.5dB; p95 four-band ILD abs error ≤baseline+1.0dB; >=8 distinct accepted final angular blocks in S1 and S2; individually report final-subject results. 2000 bootstrap draws, fixed PCG64 seed 20261031. No guarantee of actual population coverage with 2 final heads. All thresholds are engineering gates, NOT known perceptual just-noticeable differences.
If no eligible baseline with comparable coverage: INDETERMINATE; if insufficient independent blocks or unknown critical measurement plane for a claimed physical endpoint: INDETERMINATE/CLAIM_RESTRICTED; if numeric hypothesis fails: REVISE_OR_REJECT; if data invalid: INVALID. No posthoc rescue.

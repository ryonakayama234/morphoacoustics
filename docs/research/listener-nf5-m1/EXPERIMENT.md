# EXPERIMENT — M1 execution, controls, and CI plan
## Procedure and separation
M1-A: trace G0-A2 evidence to publisher edition, 2016 author paper, gain note and SOFA convention. Produce qualified vs unresolved Q1-Q6 ledger without assuming missing values.
M1-B: after D0+M1 amendment commit, execute independent source-verified **geometry-only** runner with ephemeral ZIP. Audit exact four members, coordinate finite/range, direction order across shells, clean role split, 5° buffer, no per-radius directional leakage. Emit ONLY non-acoustic JSON receipt, never raw coordinates/HRIR. Strict nonzero exit on invalid source and cleanup in finally.
M1-C: specify B0-B3 F1-F3, tests/selection/calibration/final, stationarity, source reference and future API limits; do not implement model in M1.
M1-D: synthetic negative controls for coordinate wrapping, role consistency over radii, radius holdout, angular exclusion, deterministic receipt, numerical m/ell invertibility, ILD gain invariance and phase/temporal sign; no original acoustic reads.
M1-E: verify exact-head CI and result, inspect artifact/commits and separate synthetic from original geometry. Choose status IMPLEMENTATION_READY only if geometry, rights-for-research, metrology for limited observable and operational test contracts are adequately qualified. Otherwise BLOCKED / REVISE_DESIGN with specific reasons. A green CI by itself is never that verdict.
## Practical evidence retention
- Original publisher MD5, observed ZIP SHA256, script SHA, source commit, deterministic geometry-role manifest digest, per-role direction/block counts, buffer exclusions, shell consistency, selected S1/S2 eligible counts, pipeline success and tests.
- No original file, full query table, HRIR, delay samples, long-lived publisher tokens, coefficients or unpublished per-position acoustics.
- On every failed CI preserve a human explanation even if logs are automatically discarded; no waived checks.
## Independent review before any G3b
Reviewers separate: (A) measured acoustic signal/time/channel/reference interpretation, (B) rights/edition/derivative, (C) code/holdout/CI and split. Same implementer synthetic/unit checks do not satisfy distinct scientific review.

## Selected minimal implementation
An opt-in **local Core CLI adapter** in `tools/od2_body_cli.py` based on Core main's existing `BodyPresetRegistry` (exact M0 r1) and independently verified OD-1 shape/physical runner. This first slice creates **no second mutable body registry**. A content-addressed, immutable case receipt is materialized alongside a physical study archive; readback *re-derives* identity using Core's trusted original parent and the selected family, then verifies actual output artifact hashes. No Core package-source inventory changes, Performance v0/v1 mutation or Studio UI edit. The existing unmerged site08 Core stack #145→#166 and merged Studio #27 are preserved, not copied into the product under new identity. A durable single registry beyond the current research archive is a **G3 later decision** and will not be falsely claimed.

Supported family = `tract1d.local-log-area-5.v1`; c={4,8} as exact integer, r as enum string {"0.90","1.00","1.10"}. The null returns the exact baseline **identity** rather than minting a revision. Only four nonnull derived bodies exist. Inspect/derive/perform-suite/verify/resolve are proposed opt-in CLI operations. A `perform-suite` run computes all six fresh pressure traces via unchanged OD-1 and may provide four stable physical revision refs; it is not an arbitrary single-take performance engine or published ABI.

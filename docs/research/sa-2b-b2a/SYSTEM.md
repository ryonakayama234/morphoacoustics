# B2-A SYSTEM — Static prepared character anatomy into one local wave engine

## Objective and architectural scope
Use one bidirectional physically local wave propagation algorithm for distinct characters. Morphology provides a section-specific array of SI lengths and cross-sectional areas; shared laws compute wave propagation and pressure/volume-flow reflections. B1b's equal-area propagation is a limiting case, NOT a separately offered creator playback engine. Static Fidelity 0 continues to serve its different frequency-domain diagnostic purpose.

B2-A physical route: exact versioned CC-A2 prepared body M0 or M1 -> 16 original lengths/areas -> local pressure-wave cells -> lossless junction impedance scattering -> original unchanged B0 physical mouth inertance/resistance -> time-dependent p/U pressure/flow states. Inlet boundary is externally prescribed signed U for scientific tests, not vocal-fold self-excitation. All processing is physical wave state advancement; no post-wave equalization or arbitrary filter.

## Geometry, clock and limitation
M0 /a/: 16 x 10mm varying original /a/ areas, M1 /a/: same 16 areas at 11mm. Both from immutable PreparedMorphology via CC-A2 registry and frozen Experiment 028 reference. The uniform subdivision n=2/4/8 gives a single physically derived acoustic clock per whole static body. For M0, 68,600/137,200/274,400Hz. For M1, 62,363.636/124,727.273/249,454.545Hz. This is NOT the 48k observation/audio sample rate. It exactly honors total anatomical lengths and strict local wavefront support. Arbitrary unequal lengths within one body, continuously moving length/area, moving-wall energy and cross-clock physically coupled audio are UNSUPPORTED, not silently quantized.

## Junction physics
Wave pressure amplitudes a from upstream section and b from downstream section, with Zleft=rho*c/Aleft and Zright=rho*c/Aright. Define r=(Zright-Zleft)/(Zright+Zleft). Outgoing upstream reflected pressure =r*a+(1-r)*b; downstream transmitted pressure=(1+r)*a-r*b. Port p and U are continuous across stationary, ideal abrupt one-dimensional section junction. The independent pointwise power certificate is (a²-bref²)/Zleft=(atrans²-b²)/Zright. The lossless junction cannot be assigned artificial dissipation or add energy. Physical stored wave energy is h sum((a²+b²)/Zsection), including each separate section's impedance.

The terminal B0 instance must be constructed from the *actual outlet area* with its clock-specific capacitance-free inertance/resistance law. It stores original M*q²/2 and dissipates physical resistor power; for 200–2200Hz test frequency domain enforce lip ka<=0.8.

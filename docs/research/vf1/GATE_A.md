# VF-1A Gate A — prospective scientific registration (before code)
**Date:** 2026-10-26 JST. Creator approval: [#207](https://github.com/ryonakayama234/morphoacoustics/issues/207). Implementation tracking [#208](https://github.com/ryonakayama234/morphoacoustics/issues/208). **Model research only, NOT a validated human larynx, nor creator-usable audio.** This document is written and committed before any VF-1A implementation.

## Research question
Can a minimal **two mechanical masses** with a pressure-actuated compliant volume, an aperture-modulated nonlinear *resistive* flow, and the existing **same-time** time-domain acoustic inlet impedance be evolved with an auditable physical-work identity? Under fixed nonperiodic pressure drive, does any observed oscillation arise internally, rather than by prescribing F0, a sinusoidal area, or a WAV? **Self-oscillation onset is an outcome to measure, not an assumption or G0/G1 PASS condition.** If it does not persist, explicitly report `NO_SUSTAINED_SELF_OSCILLATION_OBSERVED`.

This is a **specified generic fluid–structure proxy**. Its internal aerodynamic pressure profile and glottal flow separation are not anatomically validated. Do not conflate energy-consistent *abstract compliant aperture* with Ishizaka–Flanagan anatomical two-mass dynamics.

## Frozen model law and sign conventions
Two displacement coordinates `x_i` [m], velocities `v_i` [m/s], masses `m_i>0` [kg], grounding springs `k_i>0` [N/m], coupling spring `k_c>=0` [N/m], damping `d_i>=0` [N s/m]. Stiffness matrix `K=[[k1+kc,-kc],[-kc,k2+kc]]`, symmetric positive definite. Effective compliant volume `V=V0+g1*x1+g2*x2`, `g_i>0` [m²]. Intraglottal aperture independently specified by tissue shape `A=A0+(w/2)*(x1+x2)` [m²], require `A>A_min>0` throughout pilot; **exact contact/closure explicitly UNSUPPORTED**. Fixed `rho=1.21kg/m³`, `Cd=0.7`.
- `m_i dv_i/dt = g_i*p - d_i*v_i - (Kx)_i`. `p` = supraglottal acoustic port pressure [Pa], positive compression pushes `x` outward.
- `I_g dq/dt = Psub - p - R_g*q - [rho/(2 Cd² A²)]*q*abs(q)`. `q` [m³/s] is glottal valve through-flow, `Psub` [Pa] is a **steady or explicitly changed external pressure reservoir**, never a sinusoidal voiced source; `I_g>0` [Pa s²/m³], `R_g>=0` [Pa s/m³].
- `Uin = q - g·v`: compliant chamber volume increase diverts valve inflow; positive `Uin` enters 1D tract. **This geometric flow identity is essential**; setting `Uin=q` while retaining mechanical pressure force `p g` would create spurious work.
- Reuse *unaltered* Experiment 032 `PassiveTract` from exact SFI-3 precursor [Draft #84](https://github.com/ryonakayama234/morphoacoustics/pull/84) `7ab18f25f53bc5f81bcdf5e7697fd11981abe6dd`. Its inlet sample `Uin_next` and reported `p_mid` are related by a **same-timestep affine passive port**. No lagged source/output filtering. Outflow matched resistive only: an ideal benchmark, NOT physical lips. Do not silently import this candidate into `main`.

## Continuous and discrete work identity (must be tested with locally scaled errors)
`E = 0.5 I_g q² + 0.5 Σ m_i v_i² + 0.5 xᵀ K x + E_tract`. For constant positive aperture and area-dependent dissipative law, with a **single implicit-midpoint** step and shared `p_mid,Uin_mid,q_mid,v_mid,x_mid`,
`ΔE = dt*[Psub_mid*q_mid - R_g*q_mid² - b(A_mid)|q_mid|³ - Σ d_i*v_i,mid²] - E_outlet_loss`.
No `p_mid*g·v_mid` extra contribution is permitted: it cancels between tissue and acoustic port. Zero-work relaxation cannot increase total energy. At variable A, the model assigns no external material-actuator work (only displacement changes it). This identity is an internally falsifiable model law, **not** a biological oracle; any omitted moving-wall aerodynamic work is a model limitation, not numerical energy license. Track contributions and discrepancies independently (tract, tissue/valve, complete) with separate local denominators (VM-1D #206 lesson).

## Frozen diagnostic fixture and input interventions
- Parameter pilot (**model units**, not human measurements): `m1=m2=1.2e-4 kg, k1=k2=30 N/m, kc=8 N/m, d1=d2=0.008 N s/m, g1=g2=3e-5 m², A0=3e-5 m², w=0.012 m, A_min=2e-6 m², I_g=1200 Pa s²/m³, R_g=1.5e6 Pa s/m³`.
- Base geometry 10 serial Core `Tract1DGeometry` sections, each length `0.017m`, area `0.0003m²`. Controlled alternate only section index 5 halved, as SFI-3. Match outlet `Zc=rho c/Aout`, subdivision `2`. `dt=1/48000s`, duration `0.06s`. Initial `x1=+2e-5m,x2=-2e-5m`; velocities, `q` and acoustic pressure/flow initially zero. This seed is explicitly an initial condition, NOT a periodic waveform.
- `Psub=0 Pa` vs `800 Pa` (constant), each with uniform vs constricted tract. The 0-Pa run establishes no-energy-growth; 800Pa run tests externally powered dynamics, not a guaranteed stable oscillator.
- Model-only component sensitivities after basic gate: singly vary grounding spring stiffness `k_i` by +10% at fixed other values and tissue force coupling `g_i` to zero only as an explicitly non-biological decoupled control. Do **not** claim the latter simulates a physically normal body. No post-render audio normalization, spectra correction, or peak suppression.

## Gate criteria frozen before code
- G0: exact precursor and source hash, declared units, reproducible JSON evidence incl. red/fail cases; invalid/nonfinite/negative masses/damping etc and nonpositive or sub-floor aperture explicitly rejected. No scientific PASS without archival receipt.
- G1 math: a separate matrix-free/tiny `2-mass` analytic oscillator control with `g=0`, zero pressure/flow and uniform acoustic state; unforced frequency `sqrt(k/m)/(2π)` for symmetric mode and `sqrt((k+2kc)/m)/(2π)` for antisymmetric mode. Independently derive midpoint work identity; zero-work total energy nonincrease with nonnegative losses. Source/duct/tissue port/energy residual normalized **within each subsystem** <=`1e-8` for nontrivial work, absolute floor `1e-12 J` (diagnostic numerical tolerance, NOT physiological validity). Midpoint algebraic equation residual <=`1e-7 * max(1,|Psub|,|p|) Pa`. Source flow direction and time-step refinement must be recorded. Deliberately violate one port flux or energy ledger: gate MUST fail. No later threshold retuning to rescue a result.
- G1 causal A/B: with one single-tissue/drive fixture, change only tract geometry; record whether **tissue trajectory** and `q` change, not just acoustic mouth output. Separate fixed-area prescribed-inlet control cannot qualify as VF-1. If none of the expected causal changes is resolved, verdict **INDETERMINATE_CAUSAL_SENSITIVITY**.
- G2: separate independent biological tissue/aerodynamic data and parameter identification **NOT AVAILABLE** => `INDETERMINATE_PHYSIOLOGY`, regardless of numerical PASS.
- G3: detect onset/offset and sustained periodicity only from the computed tissue displacements and flow under constant external `Psub`. Do not automatically call transient ringing a sustained self-oscillation. Test steady windows and transient magnitude reduction, report `NO_SUSTAINED_SELF_OSCILLATION_OBSERVED` unless measurable stationary cycle exists. No self-oscillation claim based only on a 60ms window.
- G4: no named receiver, playable Take, intelligibility or audio-quality GO. `VOICE_NO_GO_UNCHANGED`.
- If any G0/G1 criterion is unmet, preserve failure and mark `NUMERICALLY_UNRESOLVED`; continue with diagnosis but do not approve model/merge.

**Decision at completion** only `NUMERICALLY_VERIFIED_GENERIC_COMPLIANT_APERTURE` (if met), `REVISE`, `HOLD`; never public phonator API or anatomical validation.

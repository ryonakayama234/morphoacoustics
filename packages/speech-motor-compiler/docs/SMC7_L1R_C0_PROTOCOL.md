## Research distinction
Prior L1 envelope/selection research is software-only. Gate C0 is the first *real library-produced* Japanese G2P baseline and external corpus admission audit. Its developer fixtures and available public kanji-level data **cannot** pass original H1–H4 or represent the full 880 held-out text-level benchmark. Any ad-hoc smoke scores must be labeled development-only, distinct from original preregistered experiment. No full-context challenger C is trained here.

## C0 software experiment: freeze falsifiers BEFORE test/source
1. **Actual B0 text-only reader:** `pyopenjtalk==0.4.1` imported lazily only from explicit research function, reported version checked against the installed package, `g2p(source, kana=True)` executed exactly once, returning full source reading or a controlled refusal. It is *not* an L1 Selection or SMC Task. If package absent/version mismatch/dictionary unavailable, fail closed with `PROVIDER_UNAVAILABLE` or `DICTIONARY_UNVERIFIED`; no silent fake fallback, no external network by default.
2. **Dictionary provenance:** caller must supply a directory path to a pinned local Open JTalk dictionary, verify it is the active `OPEN_JTALK_DICT_DIR`, and compute deterministic hash over sorted **relative path names, sizes and full file bytes** with symlink refusal, file/count/total-bytes limits and UTF-8-safe path handling. Binding digest to the report is an integrity identity, not attestation of training data or dictionary license. Test exact content/rename change, symlink denial, forged bytes paths, non-directory.
3. **Input output boundaries:** hard source length < 257 codepoints / < 2049 bytes, raw Unicode scalar, no NFKC before the reader. Separate `SOURCE_UNSUPPORTED_FOR_L1` diagnosis (for ASCII, Japanese long mark, etc.) *without blocking text-only B0 scoring*. Reader must return exact built-in str; pure katakana (U+30A1..30FA + U+30FC) plus original punctuation/whitespace is permitted as **raw reader output**, but evaluation normalizes only through separately versioned policies. Maximum output 512 codepoints/2048 UTF-8 bytes. Empty/non-kana/hostile-type/overlong -> controlled refusal; reader exceptions -> `PROVIDER_FAILURE` not a model success.
4. **Never fake source-span alignment:** text-only `BaselineReading` is independent of L0 and is **never selected or compiled**. One-unit coarse L0 projection can be *considered later* for short no-punctuation source ONLY after separate explicit protocol and boundary tests; do NOT treat normal G2P's concatenated kana as automatically producing word or character offset evidence. This C0 adapter must not offer projection.
5. **Independent external-data audit:** read caller supplied JSONL bytes from local file under a CLI explicit path, no automatic download. Validate UTF-8 JSONL and exact built-in fields/types, single `<...>` marker pair in `normalized_pron`, target reading katakana, unique keys, document/kanji family parsed as `key.split('_',1)[0]`, and count of source eligibility. Report source file SHA-256, total, invalid row classifications, eligible samples, distinct kanji, target-reading variants, original normalized-text length distribution, without changing input bytes or emitting a score. Treat a marked target substring as a **reading substring**, NOT an original source offset or full-utterance multi-gold. Audit reports include none of H1–H4 predictive metrics.
6. **Test-independent demonstration:** use fake callable only for software unit tests, clearly labeled synthetic; execute actual library in isolated optional GitHub Actions job when possible and retain output/version/dictionary fingerprint, package wheel source and exact SHA. Unavailable provider -> remain `NOT_RUN_REAL_B0`, even if fake fixture tests pass.
7. **No hidden ranker:** no learned contextual C or C-mask here. B0 from pyopenjtalk may itself use sentence context; do not mislabel it as a context-free model. No held-out tuning, no multi-path top3 from constant variants or answer keys. Genuine contextual challenger after this stage requires separate frozen C1 design.
8. **Engineering discipline:** test-only RED observed in GitHub isolated research package, then minimum source, exact-SHA Python 3.11/3.12/3.13, root, typecheck, SV1 green and independent Codex review; each P1/P2 repaired using amendment-before-test before-code. All changes research subtree or isolated workflow only; parent #243, SMC4/5/6, Core, Studio, main/public ABI untouched.
